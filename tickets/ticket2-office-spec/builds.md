# ticket 2 - computer choices

prices checked: 2026-11-15. the computers are real listed pre-built systems. the monitor amounts are estimates, not shop quotes.

## 1. accountant

load: excel, accounting software, pdf files and browser.

bottleneck: disk speed and memory when many files are open.

choice: pulser eco 104, core i5-12400, 16 gb ram, 1 tb ssd. it does not need a gaming gpu.

trade-off: i saved money on graphics. 16 gb can be upgraded later.

## 2. sales

load: crm, browser tabs, excel and video meetings.

bottleneck: ram with many tabs and calls.

choice: pulser eco 104, core i5-12400, 16 gb ram, 1 tb ssd.

trade-off: i kept 16 gb to stay in budget, but i would add ram if it becomes slow. it is the same base pc as accounting because the work is similar, not because every worker needs the same pc.

## 3. web developer

load: code editor, local server, browser, build tools and sometimes virtual machines.

bottleneck: ram and cpu when running many tools.

choice: pulser advanced 425, core i5-14400f, 32 gb ram, 1 tb ssd, rtx 5060.

trade-off: the gpu is more than most web developers need. this is a ready-made option from the vendor; a custom pc without the gpu could save money.

## 4. designer

load: large images, design apps, and sometimes 3d work.

bottleneck: gpu and ram for large projects.

choice: pulser advanced 447, core i5-14400f, 32 gb ram, 1 tb ssd, rtx 5060 ti.

trade-off: i paid more for graphics, but kept 32 gb instead of 64 gb.

## monitors and os

i included one monitor and a licensed windows 11 home retail copy for each pc. the monitor price is only a reserve, not a verified shop price. i would check exact monitor stock and whether windows home is acceptable for company use before buying.
